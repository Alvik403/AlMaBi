# 06. Развёртывание и эксплуатация

## 6.1. Требования к серверу

| Компонент | Рекомендация |
|-----------|--------------|
| ОС | Ubuntu 22.04 LTS (или совместимая) / Windows для локальной разработки |
| Docker | Docker Engine + Compose plugin |
| Диск | Запас под `uploads/` и логи |
| Сеть | Только VPN/корп. сеть; TLS на reverse proxy |
| Python на хосте | Не обязателен (всё в контейнере) |

## 6.2. Файлы развёртывания

| Файл | Назначение |
|------|------------|
| `Dockerfile` | Multi-stage: сборка frontend + runtime Python |
| `docker-compose.yml` | Сервис `web`, порт `18001:8000` |
| `.env.example` | Шаблон переменных окружения |
| `.env` | Локальные/серверные настройки (не в git) |

## 6.3. Переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `DEBUG` | Режим отладки uvicorn при `python app.py` | `false` (в compose сейчас часто `true`) |
| `APP_HOST` | Хост bind | `0.0.0.0` |
| `APP_PORT` | Порт приложения | `8000` |
| `SESSION_SECRET` | Ключ cookie-сессий | `change-me-in-production` (**сменить**) |
| `UPLOADS_DIR` | Каталог Excel | `uploads` / в Docker `/app/uploads` |
| `RUNTIME_DIR` | Runtime | `runtime` / `/app/runtime` |
| `LOGS_DIR` | Логи | `logs` / `/app/logs` |

Генерация секрета:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

## 6.4. Быстрый старт

```bash
cd ~/AlMaBi
cp .env.example .env
# задать SESSION_SECRET
mkdir -p uploads runtime logs
docker compose up --build -d
curl -s http://127.0.0.1:18001/health
```

URL: `http://<host>:18001/` → редирект на `/dashboard/almabi-test`.

## 6.5. Порты и имя контейнера

| Параметр | Значение по умолчанию |
|----------|----------------------|
| Хост-порт | `18001` |
| Контейнер-порт | `8000` |
| `container_name` | `dashboard_web` |

**Важно:** на одном сервере с ОПиОП BI развести имена контейнеров и порты (например ОПиОП `18000`, AlMaBi `18001`). Текущее имя `dashboard_web` может конфликтовать — при совместном размещении переименовать.

## 6.6. Frontend assets

Локально:

```bash
npm install
npm run build
```

В Docker frontend собирается в stage `node:24-slim`.

## 6.7. Автозапуск

В текущем `docker-compose.yml` политика `restart` может быть не задана — рекомендуется `restart: unless-stopped`.

```bash
sudo systemctl enable docker
```

## 6.8. Бэкапы

Минимальный набор:

```bash
tar -czf almabi-backup-$(date +%F).tar.gz uploads runtime logs .env
```

## 6.9. Обновление

```bash
cd ~/AlMaBi
git pull
docker compose up --build -d
```

## 6.10. Логи

```bash
docker compose logs -f web
tail -f logs/app.log
```

Есть `x-request-id` / `request_id` в middleware логирования.

## 6.11. Тесты

```bash
docker compose build
docker compose run --rm web pytest -q
```

Покрывается: парсинг выгрузок, PQ-таблицы, pipeline, налоговые корзины, отчёты, маршруты.

## 6.12. Ручной smoke-check

1. Открыть `http://localhost:18001/` — редирект на Тест BI.
2. Загрузить обязательные выгрузки 1С.
3. Проверить свод, фильтры, drill-down, графики.
4. Открыть Тест Excel и 1–2 KPI-отчёта.
5. Проверить `/health` и `/ready`.
