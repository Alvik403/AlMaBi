# Документация проекта «Al Ma BI»

## Краткие технические характеристики

| Параметр | Значение |
|----------|----------|
| Тип системы | Внутренний BI-дашборд P&L (web) |
| Backend | FastAPI 0.115, Python 3.12, uvicorn |
| Frontend | Jinja2 + Vite + Tailwind |
| БД аналитики | Нет (факты строятся в памяти из Excel) |
| Данные | Excel `.xlsx` выгрузки 1С (бухрегистр, реализация, себестоимость, план/прогноз) |
| Аутентификация | Не реализована (доступ открыт любому, кто достучался до порта) |
| Порт по умолчанию | `18001` → контейнер `8000` |
| Контейнер | `dashboard_web` (имя в compose) |
